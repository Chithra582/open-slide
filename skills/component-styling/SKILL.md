# Component Styling Skill

## Overview
Applies consistent visual themes, responsive typography scales, and subtle transition physics across all deck slides.

## Operational Workflow
1. Load global theme tokens (colors, font families, margins).
2. Apply utility classes to slide headings, callout boxes, and code blocks.
3. Validate light/dark mode parity across all viewport aspect ratios (16:9, 4:3).
