# Slide Generation Skill

## Overview
Generates semantic React components structured as presentation slides with responsive typography, code highlighting, and fluid layouts.

## Operational Workflow
1. Parse narrative brief or markdown outline.
2. Select appropriate visual theme and layout grid.
3. Scaffold slide JSX source file via `slide-scaffolder`.
4. Validate imports against `@open-slide/core` component registry.
